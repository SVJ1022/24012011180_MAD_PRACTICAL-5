# 📱 Practical-5 — Login and Registration Using Jetpack Compose

## 🎯 Aim

Create an Android application that includes Login and Registration screens using Jetpack Compose.

## 📌 Practical Overview

This practical demonstrates building Login and Registration screens using Jetpack Compose. The UI follows the GUNI branding and includes input fields for user details, password fields, buttons, and navigation options between the Login and Registration screens.

## ✨ Features

- Login screen with Email and Password fields
- Registration screen with Name, Phone Number, City, Email, Password, and Confirm Password fields
- Login button on the Login screen
- Register button on the Registration screen
- “Forgot Password?” option on the Login screen
- Navigation link from Login to Registration
- Navigation link from Registration to Login
- GUNI heading and branded interface
- Light and dark visual appearances, as shown in the practical reference

## 🖥️ Screens

### Login Screen

The Login screen includes:
- GUNI heading
- Email input field
- Password input field
- “Forgot Password?” option
- Login button
- “SIGN UP” navigation link for new users

### Registration Screen

The Registration screen includes:
- GUNI heading
- Name input field
- Phone Number input field
- City input field
- Email input field
- Password input field
- Confirm Password input field
- Register button
- “LOGIN” navigation link for existing users

## 🔁 Screen Navigation

```text
        Login Screen
             │
       Tap "SIGN UP"
             ▼
     Registration Screen
             │
        Tap "LOGIN"
             ▼
        Login Screen
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to finish.
4. Start an Android Emulator or connect an Android device.
5. Run the application.
6. Test the Login and Registration screens and navigate between them using the provided links.

An Android application featuring Login and Registration screens was designed using Jetpack Compose, with input fields, buttons, styling, and navigation links between the two screens.
